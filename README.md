# M2B Official Releases

Kênh tải bản cài chính thức của M2B. Repository này **không chứa mã nguồn sản
phẩm**.

## Tải bản cài

Mở mục **Releases** và chọn đúng hệ điều hành:

- `m2b-<version>-windows-x64.zip`
- `m2b-<version>-linux-x64.zip`
- `m2b-<version>-macos-universal.zip` — Intel và Apple Silicon

Luôn tải kèm file `.sha256` và kiểm tra checksum trước khi cài. Xem
[hướng dẫn cài đặt](INSTALL.md).

## Trạng thái phát hành

- **Pre-release:** bản thử nghiệm; chưa dùng cho môi trường sản xuất.
- **Latest:** bản ổn định đã qua cổng kiểm thử và ký phát hành theo chính sách
  hiện hành.

Không tải M2B từ link chia sẻ, email chuyển tiếp hoặc kho không được dẫn từ
repository này.

## Báo lỗi và bảo mật

- Lỗi thông thường: tạo GitHub Issue, nhưng không đăng email khách hàng, mã đơn,
  license key, PIN hoặc ảnh chứa dữ liệu riêng tư.
- Lỗ hổng bảo mật: dùng **Security → Report a vulnerability** để gửi riêng cho
  nhóm phát triển. Xem [SECURITY.md](SECURITY.md).
